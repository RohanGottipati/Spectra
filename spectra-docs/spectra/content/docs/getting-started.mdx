from spectra import Agent, Config

config = Config(

### Step 3: Test in Sandbox

Run your agent in our secure testing environment:

```python
# Sandbox mode - risk-free testing
agent.deploy(environment='sandbox')

# Run test trades
results = agent.run_backtest(
    start_date='2026-01-01',
    end_date='2026-01-17',
    initial_capital=100000
)

print(f"Sharpe Ratio: {results.sharpe_ratio}")
print(f"Max Drawdown: {results.max_drawdown}")
print(f"Win Rate: {results.win_rate}")
````

<Callout type="info">
  **Tip:** Use the sandbox environment to validate your agent's performance
  across different market conditions before going live.
</Callout>

### Step 4: Deploy to Production

Launch with automatic circuit breaker protection:

```python
# Deploy to production with circuit breaker
deployment = agent.deploy(
    environment='production',
    circuit_breaker=True,
    alert_email='your-email@example.com'
)

# Monitor in real-time via dashboard
print(f"Agent deployed: {deployment.agent_id}")
print(f"Monitor at: https://spectra.ai/dashboard")

# Set up webhooks for critical events
agent.on_anomaly_detected(
    callback=notify_team,
    alert_level='critical'
)
```

## Safety & Control Features

Spectra provides comprehensive safety controls:

- **Position Size Limits** - Enforce maximum position sizes to limit exposure per trade
- **Daily Loss Caps** - Automatic agent halt if daily losses exceed configured threshold
- **Frequency Controls** - Limit transaction frequency to prevent excessive trading
- **Strategy Restrictions** - Define allowed trading strategies and prevent unauthorized actions
- **Real-Time Alerts** - Instant notifications for anomalies and risk events
- **Circuit Breaker** - On-chain protection that instantly halts agents on critical events

## Configuration Parameters

| Parameter            | Type     | Description                                          |
| -------------------- | -------- | ---------------------------------------------------- |
| `maxPositionSize`    | number   | Maximum size for a single position                   |
| `maxDailyLoss`       | number   | Stop trading if daily loss exceeds this amount       |
| `riskTolerance`      | string   | Risk level: 'conservative', 'moderate', 'aggressive' |
| `maxFrequencyPerMin` | number   | Maximum trades allowed per minute                    |
| `allowedStrategies`  | string[] | List of allowed trading strategies                   |
| `preferredTokens`    | string[] | Tokens the agent can trade                           |

<Callout type="warn">
  **Important:** Always start with conservative parameters in the sandbox
  environment. Gradually increase risk tolerance after validating agent
  behavior.
</Callout>
