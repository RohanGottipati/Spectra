# API Reference

Complete reference for the Spectra SDK and REST API.

## Authentication

All API requests require authentication using your API key.

```bash
Authorization: Bearer YOUR_API_KEY
```

Store your API key in an environment variable:

```bash
export SPECTRA_API_KEY=your-api-key
```

<Callout type="warn">
  Never commit your API key to version control. Always use environment variables
  or a secrets manager.
</Callout>

## Agent Configuration

### Config Object

Configuration parameters for controlling agent behavior:

```typescript
interface Config {
  maxPositionSize: number; // Max size for a single position
  maxDailyLoss: number; // Stop trading if daily loss exceeds this
  riskTolerance: "conservative" | "moderate" | "aggressive";
  maxFrequencyPerMin: number; // Max trades per minute
  allowedStrategies: string[]; // Allowed trading strategies
  preferredTokens?: string[]; // Preferred tokens to trade
  description?: string; // Agent description
}
```

## Deployment

### Sandbox Deployment

Test your agent in a risk-free environment:

```python
# Deploy to sandbox
agent.deploy(environment='sandbox')

# Run backtesting
results = agent.run_backtest(
    start_date='2026-01-01',
    end_date='2026-01-17',
    initial_capital=100000
)

print(f"Sharpe Ratio: {results.sharpe_ratio}")
print(f"Max Drawdown: {results.max_drawdown}")
print(f"Win Rate: {results.win_rate}")
```

### Production Deployment

Deploy with automatic circuit breaker protection:

```python
# Deploy to production
deployment = agent.deploy(
    environment='production',
    circuit_breaker=True,
    alert_email='your-email@example.com'
)

print(deployment.agent_id)  # Agent ID for monitoring
```

## REST API Endpoints

### Log Trade

**POST** `/api/v1/trade`

Log a trade for behavior analysis.

#### Request Body

```json
{
  "agentId": "alpha",
  "action": "buy",
  "token": "SOL",
  "amount": 1000,
  "timestamp": "2026-01-17T10:00:00Z",
  "strategy": "momentum",
  "confidence": 0.85
}
```

#### Response

```json
{
  "success": true,
  "tradeId": "trade_12345",
  "behavior": "conservative",
  "riskScore": 15
}
```

### Get Agent Status

**GET** `/api/v1/agent/:agentId`

Retrieve current agent behavior status.

#### Response

```json
{
  "agentId": "alpha",
  "status": "running",
  "behavior": "conservative",
  "totalTrades": 145,
  "dailyPnL": 2500,
  "riskScore": 25,
  "lastUpdated": "2026-01-17T10:05:00Z"
}
```

### Get Analytics

**GET** `/api/v1/analytics`

Get aggregated behavior analytics.

#### Query Parameters

| Parameter   | Type   | Description         |
| ----------- | ------ | ------------------- |
| `agentId`   | string | Filter by agent ID  |
| `startDate` | string | ISO 8601 start date |
| `endDate`   | string | ISO 8601 end date   |

#### Response

```json
{
  "totalTrades": 500,
  "winRate": 0.62,
  "sharpeRatio": 1.8,
  "maxDrawdown": 0.15,
  "behaviorBreakdown": {
    "conservative": 0.7,
    "aggressive": 0.2,
    "anomalous": 0.1
  }
}
```

## Webhooks

### Event Types

Subscribe to real-time events:

#### `agent.rogue_detected`

Triggered when an agent exhibits rogue behavior.

```json
{
  "event": "agent.rogue_detected",
  "timestamp": "2026-01-17T10:00:00Z",
  "data": {
    "agentId": "alpha",
    "riskScore": 87,
    "reason": "High frequency trading detected"
  }
}
```

#### `agent.anomaly_detected`

Triggered when anomalous patterns are detected.

```json
{
  "event": "agent.anomaly_detected",
  "timestamp": "2026-01-17T10:00:00Z",
  "data": {
    "agentId": "alpha",
    "anomalies": ["unusual_position_size", "rapid_liquidations"],
    "severity": "high"
  }
}
```

#### `circuit_breaker.triggered`

Triggered when circuit breaker halts an agent.

```json
{
  "event": "circuit_breaker.triggered",
  "timestamp": "2026-01-17T10:00:00Z",
  "data": {
    "agentId": "alpha",
    "reason": "Max daily loss exceeded",
    "lossAmount": 5234.5
  }
}
```

## Error Handling

### Common Errors

| Error Code | Description                      |
| ---------- | -------------------------------- |
| `401`      | Unauthorized - Invalid API key   |
| `400`      | Bad Request - Invalid parameters |
| `404`      | Not Found - Agent not found      |
| `429`      | Rate Limited - Too many requests |
| `500`      | Server Error - Internal error    |

### Error Response

```json
{
  "error": "INVALID_CONFIG",
  "message": "Max daily loss must be greater than 0",
  "statusCode": 400
}
```

## Rate Limits

- **Free Tier**: 100 requests/minute
- **Pro Tier**: 1,000 requests/minute
- **Enterprise**: Custom limits

Rate limit information is included in response headers:

```
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1642425600
```
